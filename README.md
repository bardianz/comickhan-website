# کمیک‌خوان | وب‌سایت معرفی

وب‌سایت رسمی معرفی اپلیکیشن کمیک‌خوان؛ یک صفحه ایستا و فارسی با طراحی واکنش‌گرا و راست‌چین.

## اجرا
فقط کافی است `index.html` را در مرورگر باز کنید. پروژه به فریم‌ورک، فرایند build یا سرور نیاز ندارد.

## انتشار با GitHub Pages
مخزن از طریق GitHub Actions منتشر می‌شود. در تنظیمات مخزن، بخش **Settings → Pages → Build and deployment** را روی **GitHub Actions** قرار دهید. پس از اجرای موفق workflow، وب‌سایت در آدرس زیر در دسترس خواهد بود:

https://bardianz.github.io/comickhan-website/

## ساختار
- `index.html`: تمام ساختار، استایل‌ها و تعاملات وب‌سایت
- `favicon.svg`: آیکون وب‌سایت
- `.github/workflows/pages.yml`: فرایند انتشار GitHub Pages
